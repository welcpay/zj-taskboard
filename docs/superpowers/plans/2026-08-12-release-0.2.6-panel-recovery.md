# Release 0.2.6 Panel Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatically recover the open Codex Taskboard panel after the fixed local daemon temporarily stops during an upgrade, then build and verify the complete 0.2.6 local macOS release.

**Architecture:** Keep recovery inside the injected panel controller because it owns open generations, host binding requests, iframe capabilities, and frame-ready state. Add one bounded retry controller that calls the existing authenticated host ensure path and always replaces a failed iframe; retain the independent launchd daemon and corrected non-relocatable PKG flow.

**Tech Stack:** JavaScript injector, Node test runner, Tauri 2/Rust, launchd, macOS `pkgbuild`/`productbuild`/`hdiutil`, npm release scripts.
